# Archived exploratory benchmark runners

These scripts were useful while comparing Parquet, framed binaries, Python
bridges, reader profiles, and early wrapped-Pcodec implementations. They are
retained for provenance but are not part of the current benchmark gate.

Use the current real-data records under `inst/benchmarks/` and the maintained
scripts under `scripts/` for new comparisons. The BP chr1 optimisation sweep
that selected the native defaults is recorded in
`inst/benchmarks/bp-finngen-chr1-optimization.csv`.
