# Archived numeric projection experiments

These records are the historical frontier/projection experiments associated
with the old `SE6`/native-C++ reconstruction path. They are archived because
they do not represent a complete self-contained GWAS file: the measured
payloads contain numeric semantic streams and exception arrays, but no
position or REF/ALT identity streams.

The current headline benchmark must therefore use
`inst/benchmarks/finngen-10m-bp-20260804/`, whose Pcodec size includes the
identity key.
